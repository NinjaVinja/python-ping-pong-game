# 🏓 Python Ping Pong Game

A simple **Ping Pong game** built using Python's built-in **Turtle graphics** module.

This project is a two-player game where each player controls a paddle and tries to hit the ball past their opponent.

## 🎮 Features

* 🏓 Two-player Ping Pong gameplay
* ⬆️⬇️ Right paddle controlled with **Arrow Keys**
* 🎯 Left paddle controlled with **W / S**
* ⚡ Ball speed increases after every paddle hit
* 📊 Live scoreboard
* 🔄 Ball resets automatically after a player scores
* 🖥️ Simple black-and-white game interface

## 🛠️ Technologies Used

* **Python**
* **Turtle Graphics**
* **Object-Oriented Programming (OOP)**

## 🎮 Controls

| Player       | Move Up | Move Down |
| ------------ | ------- | --------- |
| Right Paddle | `↑`     | `↓`       |
| Left Paddle  | `W`     | `S`       |

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/python-ping-pong-game.git
```

### 2. Open the project

```bash
cd python-ping-pong-game
```

### 3. Run the game

```bash
python main.py
```
